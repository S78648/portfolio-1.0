Real-Time Chat Enhancer

repo/distributed-chat-runtime

Multi-instance bidirectional chat backend designed to scale horizontally across multiple application pods using WebSocket STOMP and Redis Pub/Sub channels.

Horizontal Fanout Isolation

Recent conversation history caches in Redis with sliding-window TTLs, with asynchronous worker writes to PostgreSQL ensuring Zero message drops during high volume burst traffic.
